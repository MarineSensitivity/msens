# One self-contained storage index page

Self-contained by necessity: served straight off a bucket, so no
external stylesheet, font or script can be referenced.

## Usage

``` r
storage_page(title, subtitle = "", body_html = "", crumb = "")
```

## Arguments

- title, subtitle:

  page heading

- body_html:

  the listing table

- crumb:

  breadcrumb HTML

## Value

an HTML string
