# The grid a release's `cell_id` values index

Errors on an unknown version rather than assuming the current grid —
assuming is how v7 ids get painted on v8's grid and land in the wrong
ocean.

## Usage

``` r
grid_for_ver(ver)
```

## Arguments

- ver:

  version label, e.g. `"v6"`

## Value

a `grid_id`
